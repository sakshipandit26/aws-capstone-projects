# 📌 Overview

This repository contains **five hands-on AWS projects** developed to demonstrate practical knowledge of cloud computing, AWS services, Python automation, serverless architecture, CI/CD, monitoring, and cost optimization.

The projects were implemented using AWS services and Python where applicable.

The main objective of this portfolio is to demonstrate the ability to:

- Create and configure AWS resources.
- Automate AWS operations using Python and boto3.
- Build serverless applications using AWS Lambda.
- Host static websites using Amazon S3.
- Implement CI/CD using GitHub and AWS CodePipeline.
- Monitor AWS applications using CloudWatch.
- Automate EC2 resource management.
- Apply AWS IAM security practices.
